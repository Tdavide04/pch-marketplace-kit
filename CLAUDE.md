# pch-marketplace-kit

Contract shared by Personal Collection Hub and its Marketplace adapters. Decisions live in the hub repo (`docs/adr/0012-adapters-and-modules-as-packages.md`).

Source code, identifiers, commit messages and `README.md` are in English. Talk to the user in Italian.

A change to `domain.py` or `adapter.py` is a change to the contract: bump the version, tag it, then update the adapters and the hub.
